# 위협 헌팅 시험결과 보고서

## 현재 판정

**제품 적합 미입증 · 전체 목표 진행 중.** [시험 계획서](threat-hunting-test-plan.md)의 전체 범위를 시험 대상으로 유지한다. 이전 1차 구현에서 통과한 선택 시험은 참고 기록이며 전체 제품 합격 회차가 아니다.

최신 전체 자동 회귀 **TH-R059**는 Manager 1,200개(시나리오 815건 포함)·Logparser 525개·프런트엔드 106개·Linux Agent 240개·Windows Agent 239개, 합계 **2,310개 통과**다. Windows symlink 권한 시험 1개는 건너뛰었고 7개 단계·프런트엔드/Windows 빌드·Manager JAR 대조가 성공했다. episode 실행·병합 증거를 추가하고, 실제 SQL이 분리된 구간을 하나로 합치던 결함을 수정한 뒤 새 환경에서 전체 시험을 실행했다. 고정 소스 입력은 603개이며 변경 0건을 확인했다. 자동시험 통과는 제품 전체 적합 판정과 구분한다.

**현재 요구사항 심사는 PASS 5개·NOT_RUN 11개·NOT_IMPLEMENTED 13개·BLOCKED 3개, 총 32개이며 제품 판정은 `NOT_VERIFIED`다.** TH-M0-02와 TH-M2-02/03/04/06은 근거를 재대조했다. 이전 TH-R055에서 PASS였던 TH-M2-05는 이번 Chrome 파일 이벤트가 시간 초과되어 현재 회차를 BLOCKED로 기록한다. 이전 실제 파일 수신 증거는 보존하며, 다운로드 시작 안내를 파일 수신 성공으로 대체하지 않는다. [요구사항 심사](../output/hunt-acceptance/TH-R059/requirements.json), [시나리오 심사](../output/hunt-acceptance/TH-R059/m0-scenario-review.json), [예외·episode 부분 심사](../output/hunt-acceptance/TH-R059/m4-exception-review.json)에 근거와 한계를 연결했다. 오탐 피드백·개별 알림 억제/해제를 포함한 원래 M0~M6 전체 범위를 유지한다.

## 재실행

자동 회귀는 `manager/scripts/Invoke-HuntVerification.ps1`에 고정했다. 새 RunId로 Manager/Logparser 전체와 선택 없이 48개 의미 시험, 프런트엔드 전체/빌드, 양 OS Agent 시험을 재실행하고 원본 로그·JUnit·소스/fixture 해시를 보존한다. 자동 회귀의 녹색 결과가 전체 제품 판정을 대신하지 않도록 미검증 요구사항 추적표를 별도로 만든다. 실패 시 구현을 수정하고 같은 RunId를 덮어쓰지 않는다.

제품 출시와 goal 완료는 모든 요구사항의 구체적 증거가 확보된 뒤에만 판단한다. 현재 goal은 계속 진행 중이다.
