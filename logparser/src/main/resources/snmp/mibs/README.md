The RFC-1212, RFC-1215 and SNMPv2-CONF macros are supplied by jsmiparser (Apache-2.0).
Full standard OID definitions are used instead of its synthetic SMI root definers.
Vendor IMPORTS must be supplied by the user. No MIB is downloaded at runtime.
