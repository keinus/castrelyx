# 네트워크 흐름 기반 Laya 탐지 모델 종합 보고서

학습 중단 결과 및 추론 속도 실측 보강

작성일 2026년 10월 6일 · 대상 FlowTransformer 공개 논문의 NF-UNSW-NB15-v2 비교 실험

## 종합 결론

**현재 결과는 Laya의 진일보를 입증하지 못했다.** 완료된 두 반복에서 Laya의 F1은 평균 **93.90%**, 최상 비교군의 세 반복 평균은 **94.49%**였다. Laya가 **0.59%p 낮았고**, 오탐률도 **0.946% 대 0.832%**로 높았다. 반면 공격 탐지율은 **99.948% 대 99.756%**로 더 높았다.

**이번 설정의 F1과 오탐 성능은 비교군보다 불리하며, 그 지표에 한정하면 퇴보 방향이다.** 다만 반복이 두 번이고 비교군 학습률을 테스트 성적으로 선택했으므로 모델 자체의 일반적인 우열을 확정할 수 없다. Laya의 두 완료 체크포인트는 이번 순차 측정에서 단일 요청 p95 200ms를 충족했다. 첫 체크포인트의 p95는 최상 정확도 비교군의 4.9배였다. 실제 네트워크 자동 대응의 개선은 별도 검증 대상이다. 현재 근거만으로 기존 탐지 모델을 Laya로 대체할 이유는 충분하지 않다.

탐지 정확도는 사용자의 학습 중단 지시에 따라 저장된 결과만 종합했다. 학습은 재시작하지 않았고 이후 사용자 요청으로 추론 속도만 측정했으며, 중단된 세 번째 반복에는 성능값을 부여하지 않았다. 이 문서는 중단 시점의 결과 보고서이며 계획한 전체 벤치마크의 완료 보고서는 아니다.

## 실험 범위와 비교 기준

기준은 [FlowTransformer 공개 원문](https://arxiv.org/pdf/2304.14746v1)의 Table III UNSW-NB15 실험이다. 네트워크 흐름을 묶어 마지막 흐름을 판정하는 구조이고, 공개 데이터와 저자 코드로 모델을 재실행할 수 있어 선정했다. 원문의 네 계열과 각 두 설정, 총 여덟 설정을 비교했다. 논문의 세 데이터셋 전체나 구조·입력 인코딩·분류 헤드의 전체 탐색을 재현한 것은 아니다. [1][2]

논문에서 GPT와 BERT라고 부르는 비교군은 해당 구조를 저자 코드로 처음부터 학습한 모델이다. GPT 서비스, 사전학습 BERT 체크포인트 또는 Qwen과의 비교가 아니다. 이전 v1–v4 결과도 이번 수치에 포함하지 않았다.

| 항목 | 적용한 조건 |
|---|---|
| 데이터 | UQ 공식 NF-UNSW-NB15-v2, 2,390,275개 흐름 |
| 분할 | 원본 행 순서의 앞 2,151,248행 학습, 뒤 239,027행 평가 |
| 평가 구성 | 공격 16,271개, 정상 222,756개 |
| 입력 | 저자 선택 37개 특성 × 연속 8행, 마지막 흐름의 공격 여부 판정 |
| 입력 제외 | IP 주소, 정답 Label, 공격 이름 Attack |
| 전처리 | 학습 구간에서 적합한 수치 변환과 상위 32개 범주 처리 |
| 학습 배치 | 정상 64개와 공격 64개, 유효 배치 128, epoch당 64개 배치 |
| 학습 종료 | 최대 20 epoch, 원본 코드의 최소 개별 배치 손실 기준 조기 종료 |
| 판정 | 공격 확률 > 0.5, 테스트 기반 임계값 조정 없음 |
| 비교군 학습률 | 0.01, 0.001, 0.0005, 0.0001, 0.00001, 각 세 반복 |
| Laya | 사전학습 모델 전체 파인튜닝, 원래 이진 헤드, Adam 0.00001 |

여기서 한 epoch는 8,192회 균형 표본 추출이며, 학습 구간 전체를 한 번 통과한다는 뜻이 아니다. 모든 모델에 같은 seed별 표본 스케줄을 적용했다. Laya에는 같은 전처리 정보를 숫자 9자리 정밀도의 CSV 텍스트로 제공했다. 입력을 자르지 않도록 길이 상한을 8,192토큰으로 두었고, 완료된 두 실행에서 관측된 최대 입력은 각각 2,080·2,074토큰이었다.

## 학습률 탐색을 반영한 모델 비교

각 비교군에서 세 반복 평균 F1이 가장 높은 학습률을 선택했다. 표의 F1은 평균 ± 표본 표준편차이고 탐지율·오탐률은 평균이다. Laya는 완료된 두 반복의 평균이다. 표준편차는 적은 반복에서 관측된 변동이며 신뢰구간이 아니다.

| 모델 설정 | 선택 학습률 | 반복 | F1 % | 탐지율 % | 오탐률 % |
|---|---:|---:|---:|---:|---:|
| Shallow Encoder · Dense | 0.0005 | 3 | 94.36 ± 0.20 | 99.674 | 0.847 |
| Shallow Encoder · Projection | 0.0005 | 3 | 94.49 ± 0.20 | 99.756 | 0.832 |
| Shallow Decoder · Last token | 0.0001 | 3 | 94.15 ± 0.36 | 99.816 | 0.893 |
| Shallow Decoder · Flatten | 0.0005 | 3 | 94.00 ± 0.85 | 99.777 | 0.915 |
| GPT 구조 · Lookup | 0.0001 | 3 | 91.66 ± 0.36 | 99.693 | 1.303 |
| GPT 구조 · Dense | 0.0001 | 3 | 93.97 ± 0.71 | 99.746 | 0.917 |
| BERT 구조 · 입력 인코딩 없음 | 1e-05 | 3 | 66.66 ± 46.69 | 99.736 | 33.976 |
| BERT 구조 · Projection | 1e-05 | 3 | 39.30 ± 45.99 | 99.934 | 67.062 |
| **Laya** | 0.00001 | **2** | **93.90 ± 0.79** | **99.948** | **0.946** |

테스트 F1로 학습률을 선택했으므로 비교군 결과에는 선택에 따른 낙관성이 있다. 독립 검증 성적이 아니다. Laya에는 한 학습률만 적용해 탐색량도 다르다. 추가 탐색은 기본 설정 BERT의 수렴 실패를 확인한 뒤, Laya의 첫 테스트 평가 전에 조건을 고정한 사후 민감도 분석이다. 이런 비대칭 때문에 수치 차이를 모델의 본질적 한계로 해석해서는 안 된다.

BERT 계열은 낮은 학습률에서도 반복별 변동이 컸다. 높은 평균 탐지율과 함께 매우 높은 오탐률이 나온 것은 일부 반복이 거의 모든 흐름을 공격으로 판정했기 때문이다. 특정 반복의 수렴 실패를 BERT 일반의 성능으로 확대하지 않는다.

## 같은 두 seed로 비교한 결과

반복 수 차이를 확인하기 위해 최상 비교군의 설정을 그대로 두고 Laya와 공통인 두 seed만 따로 비교했다. 학습률을 이 두 반복에 맞춰 다시 고르지 않았다.

같은 두 seed에서도 Laya F1 평균은 **93.90%**, 비교군은 **94.44%**로 Laya가 **0.55%p 낮았다**. 평균 누락은 46.0개에서 8.5개로 줄었지만, 평균 오탐은 1863.5개에서 2107.0개로 늘었다. 두 반복 모두 같은 방향이지만 반복 수가 적고 테스트 기반 설정 선택이 있어 통계적 우월성·열등성을 확정하지 않는다.

## 학습 구간과 동일 특성이 있는 평가 흐름

평가 행 59,793개, 약 25.02%는 학습 구간에도 같은 37개 입력 특성을 가진 행이 있다. 같은 원본 패킷이나 연결이 중복 수집됐음을 확인한 것은 아니다. 이 행들을 제외한 179,234개에 같은 모델의 예측을 집계한 결과는 다음과 같다.

| Laya 평가 대상 | F1 평균 % | 탐지율 평균 % | 오탐률 평균 % |
|---|---:|---:|---:|
| 전체 | 93.90 | 99.948 | 0.946 |
| 동일 특성이 학습 구간에 없는 행 | 92.21 | 99.952 | 1.250 |

하위 집단의 구성과 공격 비율도 달라지므로 F1 하락 전부를 암기나 데이터 누수의 효과라고 단정할 수 없다. 중복을 제거하고 다시 학습한 실험도 아니다.

## 속도와 자원 및 자동 대응 평가

학습 중단 뒤 추론 속도를 별도 측정했다. 아래 실측 절의 원시 요청 시간을 사용했고 배치 평가 총시간이나 [5]의 모델 카드 속도로 대체하지 않았다.

Laya의 파라미터 수는 **421,293,827개**, 최상 비교군은 **350,529개**로 약 **1,202배** 차이다. 이는 파라미터 수 비교이며 지연·GPU 메모리·처리 비용이 같은 배율이라는 뜻은 아니다. Laya는 RTX 4090에서, 비교군 학습은 RTX 2080 Ti에서 수행했으므로 학습 시간으로 하드웨어를 통제한 속도 우열을 판단할 수 없다.

QoS 조정, 라우팅 변경, 선택적 패킷 차단, 호스트 차단은 실행하거나 효과를 측정하지 않았다. 현재 출력은 이진 탐지이며 대응 방책 선택의 정확도를 평가한 결과가 아니다. window 수집·흐름 종료 대기·대기열·장비 적용을 포함한 공격 확산 억제 시간도 검증되지 않았다.

## 저장된 체크포인트의 추론 속도 실측

Laya의 두 완료 체크포인트는 이번 순차 측정에서 단일 요청 p95 200ms를 충족했다. 첫 체크포인트의 p95는 최상 정확도 비교군의 4.9배였다.

학습 중단 후 사용자 요청에 따라 추론만 실행했다. 모델은 기존 완료 체크포인트이며 가중치 해시가 측정 전후 동일함을 확인했다. 비교군은 본문에서 평균 F1로 선택한 학습률의 첫 seed, Laya도 첫 완료 seed를 사용했다. Laya의 두 번째 완료 seed에는 단일 요청 지연 확인만 추가했다. 속도가 잘 나오는 체크포인트를 골라 바꾸지 않았다.

모든 모델을 같은 RTX 4090에 하나씩 로드했다. WSL2 환경이며 측정 직전 네 번의 GPU 사용률은 0~2%였다. 화면 출력에도 사용하는 GPU라 운영체제의 간섭까지 제거한 전용 장비 측정은 아니다. 배치 1·8·128별로 네 배치를 워밍업한 뒤, 고정된 50개 무작위 학습 배치를 각각 네 번 측정했다. 처리량은 배치별 네 반복의 중앙값을 낸 후 50개 평균으로 계산했다. 단일 요청 p50·p95는 직렬화·토큰화 또는 수치 입력 조립을 포함한 개별 요청 200개의 지연에서 계산했다.

| 모델 설정 | 단일 요청 p50 ms | 단일 요청 p95 ms | 배치 8 판정/초 | 배치 128 판정/초 |
|---|---:|---:|---:|---:|
| encoder_dense | 10.50 | 15.21 | 546.1 | 7741.2 |
| encoder_projection | 10.53 | 16.22 | 536.8 | 7659.3 |
| decoder_last | 11.05 | 19.92 | 529.2 | 7967.2 |
| decoder_flatten | 10.60 | 16.36 | 545.0 | 7661.0 |
| gpt_lookup | 18.90 | 54.79 | 148.2 | 2360.8 |
| gpt_dense | 18.84 | 63.39 | 181.6 | 2621.2 |
| bert_none | 13.65 | 36.17 | 174.5 | 2433.5 |
| bert_projection | 14.16 | 42.64 | 179.3 | 2583.0 |
| laya | 29.61 | 80.03 | 43.3 | 44.5 |

Laya 두 번째 완료 체크포인트의 p50은 **28.53ms**, p95는 **76.37ms**다. 두 번째 체크포인트의 배치 처리량은 별도로 측정하지 않았다.

단일 요청은 같은 50개 window를 네 번씩 실행한 표본이며, 독립적인 200개 입력이나 장시간 운영 측정이 아니다. seed 20261005: 200ms 이내 100.0%, 최대 112.89ms; seed 20261006: 200ms 이내 100.0%, 최대 88.93ms.

한 판정은 8개 흐름 window의 마지막 흐름에 대한 판정이다. Laya의 논리 배치 128은 메모리 한도에 따라 16개씩 순차 실행했다. 처리량 열은 사전 인코딩한 입력부터 CPU 확률 반환까지이며 직렬화·토큰화는 제외한다. 단일 요청 지연 열에는 해당 입력 준비와 CPU/GPU 전송·확률 회수가 포함된다.

**측정 시작점은 이미 전처리된 수치·범주형 window다.** 원시 Zeek 로그 파싱·수치 정규화, 8개 흐름을 모으는 시간, 동시 요청 대기열, 네트워크 전송, QoS·차단 정책 적용은 포함하지 않는다. 모델 로딩과 최초 컴파일도 제외한 warm 지연이다. 따라서 이 수치가 공격 발생부터 실제 차단까지의 200ms나 고부하 SLA를 보장하지 않는다.

TensorFlow 비교군은 float32와 tf.function, Laya는 float32 가중치·BF16 autocast·SDPA를 사용했다. 같은 수치 커널을 비교한 것이 아니라 이번에 학습·평가에 사용한 실행 구현을 비교한 결과다. 생성형 LLM의 텍스트 응답 생성 속도와는 비교하지 않았다.

## 논문 발표값과 재현의 한계

아래 발표값은 원문 Table III의 참고치다. 원문은 90:10 분할을 명시하지만 공개 UNSW 예제는 97.5:2.5를 사용한다. 정확한 평가 행 목록, 설정별 최적 학습률과 seed도 공개되지 않았다. 따라서 Laya의 수치가 발표 F1보다 높아도 논문 모델을 능가했다는 근거로 삼지 않는다. 판단의 기준은 이번에 같은 평가 행에서 다시 실행한 비교군이다. [1][2]

| 설정 | 논문 F1 % | 이번 최고 단일 반복 F1 % |
|---|---:|---:|
| Shallow Encoder · Dense | 90.45 | 94.53 |
| Shallow Encoder · Projection | 90.43 | 94.62 |
| Shallow Decoder · Last token | 88.94 | 94.42 |
| Shallow Decoder · Flatten | 87.91 | 94.59 |
| GPT 구조 · Lookup | 89.98 | 92.02 |
| GPT 구조 · Dense | 89.95 | 94.57 |
| BERT 구조 · 입력 인코딩 없음 | 87.74 | 94.18 |
| BERT 구조 · Projection | 76.23 | 92.40 |
| Laya | 해당 없음 | 94.45 |

최고 단일 반복은 모델별 학습률·반복 중 최대 테스트 F1이며 낙관적 선택값이다. 주요 비교에서는 평균과 변동도 함께 제시했다. 비교군은 15회씩 시도했으나 Laya는 두 번만 완료해 최고값의 선택 기회도 다르다.

여덟 비교 설정 모두 원문 파라미터 수와 일치했고 입력 조립을 저자 pandas 처리와 대조했다. 그러나 파라미터 수 일치가 완전한 원문 재현을 의미하지는 않는다. 원문의 Dense embedding 설명과 공개 코드의 linear activation이 다르고, BERT 두 설정은 TensorFlow XLA 컴파일 오류 때문에 모델 전체 JIT을 해제했다. 수치 특성 순서는 환경 간 일관성을 위해 정렬했다. Adam epsilon과 정밀도·프레임워크·GPU도 서로 다르다. 세부 근거와 실패 기록은 실험 README와 프로토콜에 보존했다.

## 미학습 공격과 연관 탐지에 대한 판단

**미학습 공격 탐지 능력은 이번 실험으로 평가하지 못했다.** 모든 공격 종류가 학습 구간에 들어 있으며, 공격 종류를 학습에서 제외하는 평가가 없었다.

**단일 로그로는 탐지할 수 없는 이상을 연관 분석으로 찾아냈다는 증거도 없다.** 8개 흐름을 입력했지만 v2 CSV에는 흐름 시작 시각이 없고, 행의 인접성이 시간·호스트·다단계 공격 관계를 보장하지 않는다. 같은 모델의 단일 흐름 대조 학습이나 문맥 제거 비교도 없었다. 따라서 성능을 Laya의 연관 추론 능력 때문에 얻었다고 설명할 근거가 없다.

이 한계는 Laya가 그런 능력이 없다는 증명이 아니라, 선택한 데이터와 평가 방식이 사용자의 핵심 가설을 충분히 검증하지 못했다는 뜻이다. 이번 보고서의 결론은 공개 흐름 데이터에서의 이진 지도학습 성능에 한정한다.

## 최종 평가

**진일보 여부는 입증되지 않았다. 관측된 F1·오탐 성능만 보면 현재 Laya 설정은 최상 비교군보다 퇴보했으며, 탐지율은 소폭 개선됐다.** 동일한 두 seed 비교에서도 이 방향은 유지됐다. 그러나 두 반복과 비대칭 탐색만으로 Laya 모델 전체의 열등성을 일반화할 수 없고, 미학습 공격·실제 연관 탐지·자동 대응 효과는 검증되지 않았다. 추론은 두 Laya 체크포인트 모두 p95 200ms 이내였지만, 첫 체크포인트의 p95는 최상 정확도 비교군보다 4.9배 길었다. 현재 수치는 새로운 실시간 보안 라우터의 우월성을 주장하거나 기존 모델을 대체하는 근거로는 부족하다.

## 근거 자료와 보존 상태

서버에서 저장된 정답·행 번호·예측 확률로 기본 실험 26회와 비교군 120회 시도를 재검산했다. 데이터 및 학습 표본 스케줄 해시도 확인했다. 첫 Laya의 원본 예측 파일은 로컬 SHA-256과 혼동행렬을 다시 확인했다.

초기 종합 때는 SSH 연결 종료로 두 번째 Laya의 원본 예측 파일을 회수하지 못했으나, 추론 속도 측정을 위해 다시 접속하면서 회수했다. 두 완료 반복의 원본 예측 파일을 로컬에 보관하고, 기존 SHA-256 및 혼동행렬과 일치하는지 확인했다. 비교군 전체 119회의 원본 예측 NPZ는 서버에 보존하며 로컬 묶음에는 전체 시도별 성적표와 해시를 포함한다.
