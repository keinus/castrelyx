브라우저에서 확인한 devicePixelRatio는 1입니다. 캡처 도구가 반환한 픽셀 크기는 CSS viewport와 약간 다르므로 동일하다고 가정하지 않았습니다. 비교 이미지는 반환된 실제 이미지 폭을 기준으로 정규화했습니다. 캡처에서 보이는 일부 축소/텍스트 부드러움은 브라우저 렌더링·캡처 과정의 차이로 취급했습니다.

원본 관리자 영역은 `(12,48)–(1012,852)`의 1000×804px, 사용자 영역은 `(12,910)–(1012,1491)`의 1000×581px입니다. 구현 캡처에서는 40px의 프로토타입 도구 영역을 제외하고, 1000px 폭으로 비율을 유지해 정규화했습니다. 사용자 화면 하단의 빈 viewport는 비교에서 제외했습니다. 집중 비교는 실제 CTA와 안내 영역을 각각 잘라 폭을 맞췄습니다.

**원본은 두 개의 요약 화면, 구현은 전체 업무 화면으로 확장한 결과**입니다. breadcrumb, 상세 탭, 서명 기한, 교체 준비, 내 요청·사용 이력 링크를 추가했기 때문에 전체 높이는 일치하지 않습니다. 이 차이를 숨기거나 픽셀 단위 복제라고 평가하지 않았습니다. 주요 영역 배치·정보 순서·색상 방향·행 밀도·CTA 관계를 비교했습니다.

## 빌드와 제한

`npm run build` 성공. Vite 클라이언트 빌드와 scaffold의 Sites 출력 준비가 완료되었습니다. 실제 게시나 운영 서버 연결은 수행하지 않았습니다.

SAP 테마 패키지의 `--sapThemeMetaData-Base-baseLib` 내부 JSON 표기에 대해 esbuild CSS minifier가 5개 경고를 출력합니다. 빌드는 성공했으며 검토한 화면의 브라우저 콘솔 오류와 시각 문제는 없었습니다. 공급 패키지를 수정하거나 경고를 숨기지 않았습니다. 운영 번들 최적화 시 해당 메타데이터와 사용하지 않는 폰트 범위를 검토할 수 있습니다.

운영 연동 전 추가 확인: 실제 인증/CSRF/세션 만료, 인가 경계, CSR 서명 검증, 백엔드 경합·승인 만료, 모든 action payload, 많은 행의 페이지 처리, 실제 파일 업로드·다운로드, HSM 장비, 스크린 리더 전체 점검. 이 항목들은 프로토타입이 구현했다고 주장하지 않습니다.
