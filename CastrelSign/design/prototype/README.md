# CastrelSign KMS 디자인 프로토타입

React + Vite 기반의 독립 프로토타입입니다. 관리자 20개, 사용자 7개, 공통 진입 1개의 화면·탭과 주요 대화상자를 제공합니다.

현재 미리보기: <http://127.0.0.1:4317/>

## 확인 순서

1. **키 관리자 → 키 관리**: 버전 선택, 권한·의존성 탭, 교체 준비, 활성화 요청을 확인합니다.
2. **보안 담당자 → 승인 요청**: 기존 `ca-root v3` 요청을 선택하고 MFA `000000`과 영향 확인 후 승인합니다. 키 목록에서 v3가 사용 중, v2가 검증 전용으로 바뀝니다.
3. **일반 사용자 → 내 서비스 → 갱신 요청**: `예시 CSR 사용` → 내용 확인 → 요청 등록 → 내 요청 순서로 진행합니다.
4. **설정·구성**에서 보호, 수명주기, 관리자·MFA, 백업·복구, HSM·모니터링을 확인합니다.
5. 상단 **화면 목록**으로 모든 화면을 탐색하고 **화면 상태**로 예외 상태를 확인합니다.

기본 요청의 요청자는 `security.kim`, 승인자는 `security.park`입니다. 역할 선택은 설계 검토용이며 실제 인증이 아닙니다. 오류 재현용으로 임의의 데모 MFA를 입력하면 안내 메시지를 보여줍니다.

## 실행

Node.js와 npm이 있는 환경에서 이 디렉터리에서 실행합니다. 현재 검토 세션에는 개발 서버가 실행되어 있습니다. 아래 명령은 다음에 다시 실행할 때 사용합니다.

```powershell
npm ci
npm run dev -- --host 127.0.0.1 --port 4317 --strictPort
```

```powershell
npm run build
```

빌드에는 scaffold의 Sites 파일 준비 단계가 포함되어 있지만 외부에 게시하지 않습니다. 배포할 경우 별도로 `npm run test:sites`를 실행해야 합니다.

## 동작 범위

브라우저 메모리만 사용하며, 실제 서버 요청·데이터 저장·로그인·키 생성·인증서 서명은 수행하지 않습니다. 새로고침하면 초기화됩니다. `000000`은 프로토타입 전용 입력값으로 운영 인증과 관련 없습니다.

CSR은 PEM 표식과 개인키 포함 여부만 확인합니다. 암호학적 검증은 수행하지 않습니다. 파일을 서버로 전송하지 않습니다. 다운로드 파일은 설계 설명 `.txt`, 감사 내보내기는 예시 행의 `.csv`입니다.

등록 토큰 생성은 참조 행만 추가하며 토큰 원문을 만들지 않습니다. 백업·복원은 안내 화면이며 실행 기능이 없습니다. 파기는 예시 유예기간이 지나지 않아 차단됩니다. 페이지의 권한 표시는 실제 서버 인가 검증을 대체하지 않습니다.
