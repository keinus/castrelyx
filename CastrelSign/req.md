# Requirements

이 문서는 이 프로젝트의 기본 요구사항을 정의한다. 상세 요구사항은 별도 식별하고, KMS를 위한 요구사항은 report.md를 참조한다.

## 역할

이 프로젝트는 Castrelyx의 키 관리 SW의 역할을 담당하며, KMS의 기능을 제공한다.  
가급적 작은 프로젝트를 지향하고, 키 관리를 위한 필수 기능을 목표로 구현한다.

## 기본 요구사항

1. 프로젝트 시작 시 서버키를 생성하며, 프로젝트에서 키를 관리한다.
2. admin은 1회성 키 값을 발급하여 agent를 위한 키 발급을 위한 토큰을 제공한다.
3. 클라이언트에서는 API를 통해 agent의 키를 요청하며 토큰을 같이 제공한다. 프로젝트에서 서버키를 사용하여 agent의 키를 발급하여 에이전트에 제공한다.
   1. 키 발급 시 사용자는 admin 사용자에게 1회성 토큰을 제공받아야 한다.
   2. agent에서는 토큰값, agent의 호스트 정보 등을 조합하여 프로젝트에 제공한다.
   3. 프로젝트는 정보를 종합하여 agent를 관리하고, agent 키를 발급하여 전송한다. 
4. 프로젝트는 RBAC 기능을 통해 관리되며, admin, user, anonymouse 3개의 권한을 제공한다.
   1. admin 권한은 전체 기능을 제공 및 관리한다.
   2. user는 키 발급 현황 조회, 키 사용 현황 조회 등 조회 기능을 제공한다.
   3. anonymouse는 발급된 키의 인증 여부를 확인하는 기능만 사용 가능한다.
5. 이 프로젝트는 jwt를 인증자로 사용한다.
