- 시각 기준: `../design/reference/selected-dark.png` 및 `../design/prototype`의 기존 관리자·사용자 미리보기.
- 원본 캡처: `qa/source-admin.png`, `qa/source-user.png`.
- 구현 캡처: `qa/admin-desktop.png`, `qa/user-desktop.png`, `qa/review-approved.png`, `qa/admin-mobile.png`, `qa/user-mobile.png`, `qa/user-no-certificate.png`.
- 전체 나란히 비교: `qa/comparison-admin.png`, `qa/comparison-user.png`.
- 상세 나란히 비교: `qa/comparison-admin-focus.png`, `qa/comparison-user-focus.png`. 키 상세의 제목·정보·단계·CTA, 서비스 상세의 정보·갱신·다운로드·안내문을 비교했습니다.
- 데스크톱 CSS viewport 1440×960, DPR 1. 관리자 원본/구현 및 사용자 원본 캡처는 1425×950, 사용자 구현은 1440×960으로 브라우저 캡처 표면의 스크롤바 차이가 있습니다. 사용자 비교 보드에서만 구현을 1425×950으로 정규화했습니다. 원본은 보존했습니다.
- 모바일 CSS viewport 390×844, DPR 1. 표가 긴 화면은 표 내부 가로 스크롤을 사용합니다.
- 상태: 키 PRE_ACTIVE 선택, 사용자 유효 인증서 선택. 버전 번호·서비스명·날짜·행 수는 실제 검증 DB 값과 원본 예시 데이터가 달라 픽셀 동일성을 주장하지 않습니다. 원본의 데모 도구막대와 고정 만료 경고는 실제 UI에서 각각 제거/실제 조건으로 대체했습니다.

## 발견·수정 이력

1. [P2, 해결] 인증서 없는 서비스 상세가 승인 대기로 표시됨. `NO_CERTIFICATE` 상태와 최초 발급 CTA로 수정했습니다. 수정 후 `qa/user-no-certificate.png`에서 목록·상세 모두 ‘인증서 없음’을 확인했습니다.
2. [P2, 해결] 키 상세에서 보호 방식이 내부 코드 `ENCRYPTED_SOFTWARE`로 노출됨. 원본과 같은 ‘암호화 소프트웨어’, ‘ECDSA P-256’ 표시를 적용했습니다. 최종 관리자 전체·상세 비교에 반영했습니다.
3. [P2, 해결] 대화상자 닫기 후 키보드 포커스가 본문으로 이동함. 닫힐 때 실제 호출 버튼으로 복원하도록 수정했습니다. 재검증에서 활성화 요청 → 취소 후 `document.activeElement.textContent`가 ‘활성화 요청’임을 확인했습니다. 처리 중 Escape도 부모의 busy 검사에 따르도록 했습니다.
4. 구현 중 탭 변경 시 이전 응답 형식이 잠깐 재사용될 수 있는 문제를 발견했습니다. 요청 경로와 응답 상태를 결합하고 요청 취소를 처리했습니다. 서비스/토큰 및 릴리스/정책/이력 간 전환을 브라우저에서 재검증했습니다.
